# 设置与小组件

## 常用设置

打开“我的 → 软件设置”，可以调整语言、底部 Dock、动画时长、主题颜色、课程表样式和字体。学期、当前周、每天节数和上课时间属于单份课表的设置，入口是“我的 → 课表设置”。

### 自定义底部 Dock

进入“自定义Dock栏”，可以用开关添加或隐藏导航项目，拖动已显示项目右侧的排序手柄调整顺序。除了“课表”“校园”，还可以把成绩、第二课堂、培养方案、教室查询等常用功能直接放到底部 Dock。

“我的”入口始终保留，方便返回设置。页面提供 Dock 预览和“恢复默认”按钮。

### 主题颜色与字体

“主题颜色”支持“跟随系统”“背景图”和“自定义”三种取色方式。使用背景图取色前，请先在“课程表样式”中设置背景图片；选好颜色后，点击“确认”保存。

“字体”中可以开关“使用 Google 字体”，当前使用 Noto Sans SC。需要调整字号和字重时，在设备的系统设置中修改，应用会使用系统的字体缩放和粗细设置。

### 课程表样式与显示

进入“课程表样式”，可以调整课程卡片、课表网格和背景图片。页面提供示例课程和实时预览，修改设置时即可查看显示效果；示例课程不会添加到实际课表。

“显示设置”提供以下开关：

| 开关 | 作用 |
| --- | --- |
| 显示教师 | 在课程卡片中显示教师姓名 |
| 显示教室 | 在课程卡片中显示上课地点 |
| 显示课程周数 | 在课程卡片中显示课程的周数范围 |
| 显示周末 | 展示周末的课表列 |
| 显示非本周课程 | 展示当前周没有安排的课程 |

这些显示偏好为全局设置，对所有课表生效；切换或新建课表不会为每份课表单独保存一套显示偏好。背景图片的选择与裁剪方法见[课表背景图片](./course-schedule.md#课表背景图片)。

### 动画时长与开关

进入“动画时长”，拖动滑块可以预览动画速度，点击“确认”后保存时长。该时长用于页面转场、课表翻页等动画。

页面还提供动画开关，界面名称为“Dock栏页面切换动画”，可以按需开启或关闭页面切换动画。

### 应用图标

Android 用户可以在“软件设置 → 应用图标”中切换图标。其他平台不显示此设置项。

## 课表小组件

- **Android**：长按主屏幕空白处，选择小部件，添加不高山上小部件。

::: tip
由于各手机厂商系统操作逻辑不同，实际操作可能会有一定差异。
:::

- **iOS**：在主屏幕的小组件选择器中添加；可以选择课程配色或单色配色，以及标准或紧凑信息密度。
- **macOS**：从通知中心的“编辑小组件”中添加。

小组件显示当前课表内容；切换课表或修改课程后，系统可能需要一段时间刷新。没有课表数据时，iOS 小组件显示空状态，不会使用示例课程；假期状态以校历数据为准。iOS 小组件和应用名称会跟随应用语言设置进行本地化。

小组件支持夜间配色，课程配色模式下的指示条使用课程自定义颜色，并高亮正在进行的课程。应用会按上下课时间安排刷新，实际显示可能受系统刷新策略影响；没有及时更新时，可以先打开应用刷新课表。

Android 用户还可以查看“我的 → 软件设置 → 添加桌面小组件”中的添加说明和电池优化提示。

## 检查更新与预览版

Android、Windows 等提供应用内更新入口的平台，可以在“我的 → 关于 → 检查更新”查看新版本和发布说明。下载弹窗会显示安装包文件名和进度；Android 更新会选择与设备架构匹配的安装包。其他安装渠道的更新方式以对应发布渠道为准。

需要尝试预览版时，进入“我的 → 关于 → 开发者页面”：

1. 点击“检查更新”，查看正式版和预览版的检查结果。
2. 在正式版更新卡片或“更新到最新版（包括预览版）”卡片中，按提示查看发布说明并更新。
3. 如果希望日常检查也包含预览版，开启“软件更新使用预览版源”；关闭后使用正式版更新渠道。

该开关影响应用启动时和“关于”页面的更新检查；开发者页面始终同时检查两个渠道。开启后仍可收到更新的正式版提示。预览版可能包含尚未稳定的功能，日常使用可保留正式版渠道。

Android 首次打开应用或安装新版本后，会自动清理应用临时目录中下载的旧 APK 安装包，无需手动寻找这些临时文件。

## 关于与数据

“我的 → 用户手册”可以直接打开本文档站。“我的 → 关于”提供版本信息、官方网站、开发团队介绍和开发者页面等入口；认证日志和环境信息的导出方法见[故障排查](./troubleshooting.md#仍未解决)。

“我的 → 软件设置 → 清除所有数据”会移除本地课表、设置和已保存的登录状态，执行前请确认已经备份需要保留的课表。
