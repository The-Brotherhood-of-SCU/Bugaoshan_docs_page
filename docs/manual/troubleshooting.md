# 故障排查

## 登录失败

确认学号、密码和验证码正确，并检查学校认证服务是否可用。出现剩余尝试次数提示时不要连续重试；登录成功后再按需开启“记住密码”和“自动登录”。

## 页面加载或网络错误

先检查网络连接，部分校园服务还需要校园网或学校 VPN。通知、志愿四川和办事大厅使用学校网页服务，网页端的登录和维护状态可能影响应用显示。

## 课表导入失败

确认已经完成统一身份认证，选择正确学期，并检查导入数据格式。在线导入失败时可以稍后重试，或使用分享数据、教务系统抓包数据导入。

## 课表时间不符合我所在的校区？

在 我的-课表设置-时间段 中选择你所属的校区时间段。

## 附件和小组件异常

附件下载失败时检查网络、存储权限和剩余空间。小组件没有更新时打开应用刷新课表，并确认系统允许应用使用小组件。

## 仍未解决？

**对于问题的修复一般会以新版本的形式发布，因此，当您遇到无法解决的问题时，请先确认您是否正在使用最新版本。**

**基于同样的原因，我们只受理最新版本的问题。**

### 日志保存

日志是问题修复的关键所在。您可以在 不高山上/Bugaoshan App中打开**我的-关于-开发者页面-查看认证日志**，在右上角点击下载键保存。

### 环境信息保存

提供环境信息可以帮助我们更快定位问题。您可以在 不高山上/Bugaoshan App中打开**我的-关于-开发者页面-环境信息**，点击右上角复制。

### 问题反馈

我们提供了以下两种反馈问题的渠道：

- 不高山上/Bugaoshan 官方QQ群
- GitHub Issue页（参照[Issue规范](../develop/guide/contribution-guide.html#issue-%E8%A7%84%E8%8C%83)）
