# 故障排查

## 登录失败

确认学号、密码和验证码正确，并检查学校认证服务是否可用。(默认密码参照[常用服务初始密码](../manual/initial-passwords.md))

登录失败时先查看页面显示的具体失败原因，再按提示处理。

忘记密码时，可在统一身份认证登录页点击“重置密码”，按[应用内密码重置流程](./getting-started.md#忘记密码)完成安全验证后设置新密码；重置后使用新密码登录。

出现剩余尝试次数提示时**不要连续重试**，这可能会导致您的账号**暂时锁定**。

## 页面加载或网络错误

先检查网络连接，部分校园服务还需要校园网或学校 VPN。通知、志愿四川和办事大厅使用学校网页服务，网页端的登录和维护状态可能影响应用显示。

体测在夜间访问时可能提示仅限校园网；遇到这一提示，请连接校园网或学校 VPN，或换一个时段重试。

## 课表导入失败

确认已经完成统一身份认证，选择正确学期，并检查导入数据格式。在线导入失败时可以稍后重试，或使用分享数据、教务系统抓包数据导入。

## 课表时间不符合我所在的校区？

在 我的-课表设置-时间段 中选择你所属的校区时间段。

## 附件和小组件异常

附件下载失败时检查网络、存储权限和剩余空间。小组件没有更新时打开应用刷新课表，并确认系统允许应用使用小组件。

## 应用启动失败

应用启动阶段出错、进不了主界面时，会显示启动失败恢复页，页面上可以看到错误详情。

页面底部的“危险操作 / Danger Zone”提供三个清理入口，都会先弹出确认框：

- **Clear Shared Preferences**：清除本地设置，包括登录信息、用户信息和各项设置。
- **Clear Cache Directory**：清除缓存目录（桌面平台因临时目录与其他程序共用而不可用）。
- **Clear Data Directory**：清除应用数据目录，包含本地数据库。

::: warning 清理会丢失本地数据
清理应用数据会一并删除本地课表等数据，且无法撤销。执行前请确认课表已经导出备份；清理后重新打开应用，需要重新导入课表。
:::

清理后重新打开应用即可。如果清理后仍然无法启动，请在[问题反馈](#问题反馈)中附上页面显示的错误详情。

## 课前提醒没有按时送达

先确认“我的 → 软件设置 → 通知与提醒”中的“提醒”开关已打开，并且系统层面授予了通知权限（Android 13 及以上需要；之前拒绝过的话系统不会再弹窗，请按页面提示前往系统设置开启）。

然后在“排期状态”中确认已经排期了提醒，并按提示点击“立即重新排期”。

**锁屏后经常收不到提醒属于已知现象**：提醒依赖系统的精确闹钟能力，Android 14 及以上系统默认不授予“精确闹钟”权限，未授权时会降级为非精确唤醒，锁屏状态下可能有 9~15 分钟延迟。建议同时检查系统的电池优化设置是否把应用限制在后台。

另外请留意“免打扰”设置——落在免打扰时段内的提醒会被直接丢弃，而不是延后到时段结束后再提醒。

## 仍未解决？

**对于问题的修复一般会以新版本的形式发布，因此，当您遇到无法解决的问题时，请先确认您是否正在使用最新版本。**

**基于同样的原因，我们只受理最新版本的问题。**

### 日志保存

日志是问题修复的关键所在。您可以在 不高山上/Bugaoshan App中打开**我的-关于-开发者页面-查看认证日志**，在右上角点击下载键保存。

### 环境信息保存

提供环境信息可以帮助我们更快定位问题。您可以在 不高山上/Bugaoshan App中打开**我的-关于-开发者页面-环境信息**，点击右上角复制。

### 问题反馈

我们提供了以下两种反馈问题的渠道：

- 不高山上/Bugaoshan 官方QQ群
- GitHub Issue页（参照[Issue规范](../develop/guide/contribution-guide.html#issue-%E8%A7%84%E8%8C%83)）
