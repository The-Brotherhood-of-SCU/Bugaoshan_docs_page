# 快速入门

本页介绍不高山上的下载安装、首次启动、统一身份认证和课表导入。

## 下载与安装

iPhone、iPad 用户请使用下方的 App Store 入口；Android、Windows 安装包可从项目的 [GitHub Releases](https://github.com/The-Brotherhood-of-SCU/Bugaoshan/releases/latest) 页面获取。

::: tip 无法连接Github?
您可以加入官方QQ群（1102483776），从群文件下载安装包。
:::

- **iPhone / iPad**：前往 [App Store 下载不高山上](https://apps.apple.com/cn/app/%E4%B8%8D%E9%AB%98%E5%B1%B1%E4%B8%8A/id6813305962)，点击“获取”安装。系统版本与设备兼容性以 App Store 页面为准。
- **Android**：不确定设备架构时，选择文件名带有 `universal` 的 APK。
- **Windows**：下载 `windows_x64` ZIP，完整解压后运行程序，不要单独移动可执行文件。
- **Linux**：目前没有随正式版 Release 发布的 Linux 安装包，需要按 [Linux 部署指南](./linux-deployment.md) 从源码构建。

Linux 的构建和运行需要 Linux 系统提供 GTK、WPE WebKit 等桌面依赖；macOS 的安装渠道以公告和 Release 页面实际提供的制品为准。

## 首次启动

1. 阅读并同意最终用户许可协议。
2. 查看首次启动向导。
3. 在“登录与导入课表”步骤完成统一身份认证并导入课表。
4. Android 用户可继续查看桌面小组件说明。
5. 点击“开始使用”。

登录和导入课表可以跳过，之后可从“我的”和“课表”页面完成。

## 统一身份认证登录

1. 打开底部 Dock 中的“我的”。
2. 点击顶部登录状态卡片，进入“统一身份认证登录”。
3. 输入学号、密码和验证码，按需选择“记住密码”和“自动登录”。
4. 点击“登录”。

登录失败时请检查账号、密码和验证码，不要连续尝试错误密码，以免学校账号被锁定。

### 忘记密码

在“统一身份认证登录”页面点击“重置密码”，无需先登录即可完成学校认证中心的三步重置流程：

1. **确认账户**：输入学号和图形验证码，点击“下一步”。验证码不清楚时可以刷新。
2. **安全验证**：选择账号已绑定的手机或邮箱，点击“发送验证码”，收到后填写验证码并继续。可用验证方式由学校账号的绑定信息决定。
3. **重置密码**：输入新密码并再次确认，按页面要求设置至少 8 位、包含大小写字母、数字和特殊字符的密码，点击“确定”。

显示重置成功后，点击“返回登录”，使用新密码登录。如果之前保存过密码，请在登录页更新为新密码。无法接收验证码或没有可用验证方式时，请按学校统一身份认证中心的提示处理。

## 导入第一份课表

1. 打开“课表”页面，选择“导入课表”。
2. 选择“从教务系统在线导入”；未登录时先完成统一身份认证。
3. 选择学期，需要多个学期时可选择“全部导入”。

应用还支持从分享数据或教务系统抓包数据导入。多份课表可在“我的 → 课表管理”中切换和管理。

首次启动不会自动创建默认课表。课表为空时，页面提供“导入课表”和“新建课表”快捷入口；已导入的课表也会显示在向导的导入步骤中。

## 再次查阅手册

打开“我的 → 用户手册”，可以直接访问本文档站。“我的 → 关于 → 官方网站”提供项目官网入口；检查更新的方法见[设置与小组件](./settings-and-widgets.md#检查更新与预览版)。
