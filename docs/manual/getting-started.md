# 快速入门

本页介绍不高山上的下载安装、首次启动、统一身份认证和课表导入。

## 下载与安装

请从项目的 [GitHub Releases](https://github.com/The-Brotherhood-of-SCU/Bugaoshan/releases/latest) 页面获取正式发布版本。

- **Android**：不确定设备架构时，选择文件名带有 `universal` 的 APK。
- **Windows**：下载 `windows_x64` ZIP，完整解压后运行程序，不要单独移动可执行文件。
- **Linux**：下载 `linux_x64` `tar.gz`，解压后运行；通知等 WebView 功能需要系统提供 WPE WebKit 运行库。

主发布流程当前自动构建 Android、Windows 和 Linux。iOS、macOS 的安装渠道以公告和 Release 页面实际提供的制品为准。

## 首次启动

1. 阅读并同意最终用户许可协议。
2. 查看首次启动向导。
3. 在“登录与导入课表”步骤完成统一身份认证并导入课表。
4. Android 用户可继续查看桌面小组件说明。
5. 点击“开始使用”。

登录和导入课表可以跳过，之后可从“我的”和“课表”页面完成。

## 统一身份认证登录

1. 打开底部 Dock 中的“我的”。
2. 点击顶部登录状态卡片，进入“统一身份认证登录”。
3. 输入学号、密码和验证码，按需选择“记住密码”和“自动登录”。
4. 点击“登录”。

登录失败时请检查账号、密码和验证码，不要连续尝试错误密码，以免学校账号被锁定。

## 导入第一份课表

1. 打开“课表”页面，选择“导入课表”。
2. 选择“从教务系统在线导入”；未登录时先完成统一身份认证。
3. 选择学期，需要多个学期时可选择“全部导入”。

应用还支持从分享数据或教务系统抓包数据导入。多份课表可在“我的 → 课表管理”中切换和管理。
