# 课表使用

## 管理多份课表

打开“我的 → 课表管理”，可以新建、切换、重命名和删除课表。导入同名课表时，选择添加名称后缀或更新现有课表，应用不会静默覆盖。

课表页面顶栏提供课表快捷切换按钮，可以在不同学期的课表之间一键切换，菜单中也提供“管理课表”入口。

## 导入课表

课表页面支持以下方式：

- **从教务系统在线导入**：登录后选择学期并获取课程。
- **从分享导入**：粘贴由不高山上导出的课表分享数据。
- **从教务系统抓包导入**：粘贴符合页面要求的课程数据。

导入课表时会优先根据教务处的校区信息判定主导校区，并自动应用该校区的预置时间表（上课时间和节次安排），减少手动调整。

应用还会根据匹配的校历设置学期开始日期和学期周数。导入后建议检查“我的 → 课表设置”中的日期和时间段；需要调整校区时间表时，可进入“时间段”选择对应校区。

## 编辑课程

打开课程详情可以修改课程名称、教师、教室、周次、节次和颜色，也可以手动添加课程或删除不再需要的课程。修改后保存即可同步到当前课表。

### 复制课程

1. 点击课程卡片打开详情，选择“复制”。
2. 在“新建副本”页面中调整课程名称、周次、星期和节次等信息。
3. 点击“保存”，将副本添加到当前课表。

复制不会修改或覆盖原课程；在编辑副本时取消或返回，不会生成副本。

## 周次和假期

在课表设置中调整当前学期、当前周、每天节数和每节课时间。遇到调休或假期课程时，请以学校通知为准，并在课程编辑中调整实际周次。

学期尚未开始时，课表会显示当前周数，并在页面左上角标记“未开学”。开学后，应用会按当前日期和校历显示正常课表状态。

假期中，课表页会显示放假信息，并在取得下学期校历后显示下学期名称、开学倒计时等信息。已导入对应课表时，可以点击“查看下学期课表”；按钮不可用时，先导入下学期课表。

课表日期栏还会标记节假日和节气。查看其他周次后，从后台或最小化状态返回应用不会自动跳回当前周；需要回到当前周时，可使用页面上的“本周”入口。

## 课程显示设置

打开“我的 → 软件设置 → 课程表样式”，可以调整教师、教室、课程周数、周末和非本周课程的显示。这些偏好对所有课表生效，切换课表后保持一致；详细说明见[课程表样式与显示](./settings-and-widgets.md#课程表样式与显示)。学期日期、周次和时间段则在“我的 → 课表设置”中按课表管理。

## 课表背景图片

在“我的 → 软件设置 → 课程表样式”中选择背景图片后，会进入裁剪编辑器，可以拖动和缩放调整背景图片在课表中的显示区域；直接返回则按默认方式铺满显示。新设置的图片不会沿用上一张图片的显示区域。页面还可以调整背景图片不透明度；课表背景带有渐变和淡入淡出效果。

## 导出

打开课表的导出菜单，可以选择：

- **复制到剪切板**：复制课表分享数据，供另一台设备通过“从分享导入”读取。
- **导出为日历文件**：保存 ICS 文件，随后用支持该格式的日历应用导入。
- **添加到系统日历**：在支持的平台上直接导入课程日程。iOS 和 macOS 可以选择目标日历，Android 会交给系统日历导入界面处理。

导入系统日历前，请确认目标日历和系统日历权限。考表也提供相应的导出入口，见[考表查询](./academic-services.md#考表查询)。

导出到系统日历的日程会规范三校区教学建筑的名称和地点坐标，在 iOS 和 macOS 上可以直接通过系统日程联动地图显示与导航。
