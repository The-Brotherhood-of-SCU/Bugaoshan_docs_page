# 通知与附件

## 查看通知

应用提供三类通知来源：教务处、党委学工部和青春川大。打开“校园 → 通知”后选择对应来源，点击列表项查看正文。

通知正文可能通过校园网页加载，需要网络连接；页面中的登录、验证码和站点提示以学校网站实际要求为准。

## 下载附件

通知中的附件可以直接下载。下载完成后可在附件管理页面查看文件、按通知来源筛选、按名称或时间排序，也可以批量删除不再需要的文件。

下载失败时请检查网络和存储权限，并在通知详情中重新尝试。文件打开需要设备上存在可处理相应格式的应用。
