# 常用服务初始密码

本文整理了一份常见校园服务的初始登录信息规则，**不代表学校官方公告**。各服务可能随时间、身份类型或系统升级而调整；如果实际登录页面提示不同，请以对应服务的最新通知为准。

::: warning 安全提醒

- 初始密码只应作为首次登录时的排查线索，登录成功后请立即修改为独立且不易猜测的密码。
- 不要在公共电脑、截图、聊天记录或工单中填写完整身份证号、学号或密码。
- 本页只说明组成规则，不展示任何真实账号或密码示例。

:::

## 规则速查

| 服务 | 参考规则 | 备注 |
| --- | --- | --- |
| 校园网 | 身份证号后六位；末位为 `X` 时换为 `0` | |
| 学生卡充值、空调等 | 身份证号后六位；末位为 `X` 时换为 `0` | |
| 图书馆 | 身份证号的后六位**数字** | 结尾为`X`时为`X`的前六位数字 |
| 网站下载文献 | 身份证号后六位，`X` 小写 | |
| 学工一体化网站 | 身份证号后八位，`X` 大写 | 登录入口可能发生变化 |
| 教务处 | 身份证号后六位，`X` 大写 | |
| 财务处 | 身份证号后六位，`X` 大写 | |
| 机房 | 身份证号的后六位**数字** | 结尾为`X`时为`X`的前六位数字；也可能支持直接输入学号 |
| 创高体育 | 学号后六位 | |
| 统一身份认证 | 身份证号后六位，`x` 小写 | |
| 教育邮箱激活码 | stu@身份证号12位~17位 | 默认邮箱名是学号；24级以前的激活码未公布，根据通知可咨询85410000 |

## 遇到登录失败时

1. 确认输入的是当前在用的身份证号或学号，并检查位数、大小写和是否包含空格。
2. 不要反复尝试可能触发锁定的组合；您可以在统一身份认证中心中选择[重置密码](https://id.scu.edu.cn/frontend/login#/resetPassword)。
