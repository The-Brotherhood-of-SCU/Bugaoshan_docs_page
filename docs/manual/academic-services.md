# 学业服务

“校园”的“学业”分组提供成绩、第二课堂、方案修读情况、体测和考表等服务；“工具”中还可以查询培养方案、班级课表和课程课表。

## 成绩统计

打开“成绩统计”查看各学期成绩、学分和绩点。页面支持按学期筛选，并提供通过率等统计信息；成绩数据需要统一身份认证。

页面提供“方案成绩”“及格成绩”和“自定义统计”三个分页。拥有多份培养方案时，可在“方案成绩”和“自定义统计”中选择要查看的方案；桌面端还可以使用顶部刷新按钮重新获取成绩。

### 自定义统计

1. 切换到“自定义统计”，等待成绩加载；尚未获取数据时，点击页面上的获取按钮。
2. 按需选择培养方案，使用课程名称搜索或“必修”“选修”“任选”等筛选缩小范围。
3. 点击课程卡片选择或取消选择课程，也可以按学期选择，或用“全选”选择当前筛选结果。
4. 查看所选课程的平均绩点、加权平均分、学分及通过情况等汇总信息。

筛选和搜索只改变可见列表，之前选择的课程仍会参与统计；不需要统计的课程应取消选择。切换培养方案时会清空已选课程。

## 方案修读情况与培养方案

- **方案修读情况**：查看个人培养方案中已修、未修和进行中的课程。拥有多份培养方案（如主修、辅修、微专业）时，可在页面顶部左右滑动切换查看各方案的修读进度。
- **培养方案**：按年级和学院查询培养方案详情。

## 第二课堂

“第二课堂”用于查看、参与和预约活动，登录或绑定要求以页面提示为准。

活动详情中的海报可以保存和分享：点击海报进入全屏预览，再长按图片或点击右上角菜单，选择“保存到相册”或“分享”。保存时请按系统提示授予相册权限。

## 体测

“体测”用于查询个人体测记录和结果。夜间访问如果出现“仅限校园网访问”的提示，请连接校园网或学校 VPN 后重试，也可以在其他时段访问。登录和数据以学校系统实际状态为准。

## 考表查询

“考表查询”显示个人考试科目、时间和地点，并区分已过期的考试安排。

获取考试数据后，点击页面顶部的日历按钮，可以复制考试数据、导出 ICS 文件或添加到系统日历。iOS 和 macOS 可选择目标日历，Android 通过系统日历导入界面处理；请按系统提示授予日历权限。导出的考试地点在 iOS 和 macOS 上还可联动地图显示与导航。

## 班级课表与课程课表

“班级课表”可以按年级和班级查看公共课程安排，课表详情支持按周查看课程，可左右滑动切换周次。

“课程课表”可以按课程名称、课程代码和序号在线查询各课程教学班的课表安排，需要登录统一身份认证。
