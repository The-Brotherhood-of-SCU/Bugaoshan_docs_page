# 学业服务

“校园”的“学业”分组提供成绩、第二课堂、方案修读情况、体测和考表等服务；“工具”中还可以查询培养方案和班级课表。

## 成绩统计

打开“成绩统计”查看各学期成绩、学分和绩点。页面支持按学期筛选，并提供通过率等统计信息；成绩数据需要统一身份认证。

## 方案修读情况与培养方案

- **方案修读情况**：查看个人培养方案中已修、未修和进行中的课程。
- **培养方案**：按年级和学院查询培养方案详情。

## 第二课堂与体测

“第二课堂”用于查看、参与和预约活动；“体测”用于查询个人体测记录和结果。两项服务的登录和数据以学校系统实际状态为准。

## 考表与班级课表

“考表查询”显示个人考试科目、时间和地点；“班级课表”可以按年级和班级查看公共课程安排。
