# 用户手册

本手册面向第一次使用不高山上的同学，也适合在使用某项功能时快速查找操作步骤。建议先阅读[快速入门](./getting-started.md)，完成安装、首次启动、统一身份认证和第一份课表导入，再按需要阅读其他章节。

## 手册导航

- [快速入门](./getting-started.md) — 下载安装、首次启动、登录和导入第一份课表
- [课表使用](./course-schedule.md) — 多课表、课程编辑、周次设置和日历导出
- [学业服务](./academic-services.md) — 成绩、第二课堂、培养方案、体测、考表和班级课表
- [校园生活服务](./campus-services.md) — 办事大厅、请假、教室、校园网、余额、校历和志愿四川
- [通知与附件](./notices-and-downloads.md) — 三类通知来源、附件下载和文件管理
- [设置与小组件](./settings-and-widgets.md) — Dock、主题、课程样式、字体和桌面小组件
- [故障排查](./troubleshooting.md) — 登录、网络、导入、附件和小组件问题
- [Linux 部署指南](./linux-deployment.md) — 在 Linux 上安装依赖、从源码构建和运行应用
- [常用服务初始密码](./initial-passwords.md) — 常见校园服务的初始登录规则

## 推荐阅读顺序

1. [快速入门](./getting-started.md)：完成安装、登录和课表导入。
2. [办事大厅与请假](./campus-services.md#办事大厅)：先了解常用的校园事务办理入口。
3. [课表使用](./course-schedule.md)：了解多课表管理、课程编辑和导出。
4. [学业服务](./academic-services.md)与[校园生活服务](./campus-services.md)：按需使用其他校园服务。
5. [设置与小组件](./settings-and-widgets.md)：根据个人习惯调整应用。
6. 遇到问题时查看[故障排查](./troubleshooting.md)。

## 使用说明

应用底部 Dock 默认包含“课表”“校园”和“我的”三个入口。不同平台的界面布局可能略有差异，但手册中的页面名称和基本操作流程保持一致。

部分服务需要统一身份认证、第二课堂单独绑定、校园网或学校 VPN。遇到登录、绑定或网络限制提示时，请先满足页面列出的前置条件，再重新尝试。

如果手册与当前应用界面不一致，建议先更新到最新版本，并通过[文档站主页](../)或应用内公告确认最近变更。
