# 不高山上文档站

这是[不高山上（Bugaoshan）](https://github.com/The-Brotherhood-of-SCU/Bugaoshan)的独立文档站仓库，使用 VuePress 2 和 Plume 主题构建，发布到 GitHub Pages。

## 编写文档

见[文档撰写指南](https://bugaoshan-docs.scubro.dev/develop/guide/documentation.html)。

提交文档修改前，请确认没有把 `.pnpm-store/`、`node_modules/`、构建产物或个人信息加入提交。

## 许可证

文档站随 Bugaoshan 项目按 [AGPL-3.0](https://github.com/The-Brotherhood-of-SCU/Bugaoshan/blob/main/LICENSE) 协议发布。
